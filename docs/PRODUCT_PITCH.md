# Product pitch (100 words)

Smart Market Watchlist helps investors understand meaningful changes instead of scanning prices. Users create persistent watchlists, choose Growth, Value, or Stability, and return to an explained, ranked change feed. FastAPI and PostgreSQL store observations, events, and visit boundaries; React presents metrics and interactive history charts. Price moves crossing two percent trigger signals, while smaller updates remain visible in history. Historical data is collected with yfinance, saved as JSON, and replayed offline for reliable demonstrations. Validation rejects invalid and conflicting observations. Missing fundamentals remain explicit. Separate collection and playback keep the demo reproducible while preserving a clear path toward production ingestion.
